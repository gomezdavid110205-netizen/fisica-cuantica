Reglas de llenado

  • Capacidad: un nivel n tiene n subniveles, n² orbitales y 2n² electrones como máximo.
  • Principio de exclusión de Pauli: dos electrones del mismo átomo no pueden tener los cuatro números cuánticos iguales; en un orbital solo caben dos, con espines opuestos.
  • Principio de Aufbau: se llenan primero los subniveles de menor energía (orden de n + l; si empatan, menor n): 1s 2s 2p 3s 3p 4s 3d 4p 5s 4d 5p 6s 4f 5d 6p 7s 5f 6d 7p.
  • Regla de Hund: en subniveles con varios orbitales de igual energía, primero se coloca un electrón en cada orbital (todos con el mismo espín) y después se aparean.
  • Notación de un electrón: (n, l, mₗ, mₛ). Ejemplo: el último electrón del 3p¹ puede ser (3, 1, −1, +½).

Cómo calcular la energía de un nivel n

Eₙ = −(13,6057 eV) · Z² / n²   equivale a Eₙ = −2,17987×10⁻¹⁸ J · Z² / n²
  • Z es el número atómico (átomo con un solo electrón: H, He⁺, Li²⁺…). Para el hidrógeno, Z = 1.
  • La energía es negativa: el electrón está ligado. En n → ∞ vale 0 (ionización).
  • Radio de la órbita: rₙ = a₀ · n² / Z, con a₀ = 5,29177×10⁻¹¹ m.
Ejemplo (H, n = 3): E₃ = −13,6057 / 3² = −1,512 eV = −2,422×10⁻¹⁹ J.

Cómo calcular un salto entre niveles

  1. ΔE = E_f − Eᵢ = −13,6057 · Z² · (1/n_f² − 1/nᵢ²) eV
  2. Si ΔE < 0 (n_f < nᵢ) el átomo emite un fotón; si ΔE > 0 lo absorbe.
  3. Energía del fotón: E = |ΔE| (pasar eV → J multiplicando por 1,602×10⁻¹⁹).
  4. Frecuencia: f = E / h · Periodo: T = 1 / f · Longitud de onda: λ = c / f = h·c / E
  5. Atajo de Rydberg: 1/λ = R∞ · Z² · (1/n_f² − 1/nᵢ²), con R∞ = 1,0973731×10⁷ m⁻¹ (valor absoluto).
Ejemplo (H, 3 → 2): ΔE = −13,6057·(1/4 − 1/9) = −1,890 eV → emisión.
E = 1,890 eV = 3,028×10⁻¹⁹ J · f = 3,028×10⁻¹⁹ / 6,626×10⁻³⁴ = 4,57×10¹⁴ Hz
T = 1/f = 2,19×10⁻¹⁵ s · λ = c/f = 656 nm (rojo, serie de Balmer).
